# Zenith Client 1.12.2

Ultra-optimized Eaglercraft client replacement for Tuff Client.

### Features
- **60 FPS Mobile Engine**: Automatic resolution downscaling and WebGL performance tuning.
- **Mod Manager**: Drag and drop `.js` mods into the browser at runtime with local storage persistence.
- **Serverless P2P Hosting**: Host worlds peer-to-peer over WebRTC without paying for a cloud server.
- **Proximity Voice Chat**: HRTF 3D audio.
- **Touch HUD**: Built-in on-screen controls for mobile devices.

### How to Host on GitHub Pages
1. Push this folder to a GitHub repository.
2. In your repo, go to **Settings** -> **Pages**.
3. Choose the **main** branch and save.
4. Your client is live at `https://<username>.github.io/<repo-name>`.
